# LifeLine — календарь-таймлайн твоей жизни

Интерактивный планировщик: время идёт непрерывным потоком, задачи растягиваются мышкой, а Steam честно показывает, сколько ты реально просидел в Blender и куда ушло остальное время.

## Что внутри

- **Таймлайн** с зумом (день, неделя, месяц, год) и бесконечной прокруткой.
- **Растягиваемые блоки** на трёх дорожках: Работа, Быт, Отдых. Блок можно двигать, тянуть за края и переносить между дорожками.
- **Прогресс**: блок плавно из серого становится зелёным по мере отмеченных подзадач. Если дедлайн близко, а прогресса нет, блок краснеет и пульсирует.
- **План vs Реальность**: у задачи включается Steam-слежение по слову (например, `blender`). Если в Steam отсижено больше плана, блок получает золотую рамку и бейдж «+0.5ч».
- **Shadow Tracker**: если во время Blender-блока у тебя была запущена другая игра, под блоком появляется красная штрихованная «тень» с названием игры.
- **Статистика**: баланс недели, динамика фокуса по дням и часам, серия дней с выполненной нормой, сверка со Steam за 2 недели.

## Деплой на Render

1. Залей папку в репозиторий на GitHub.
2. На [render.com](https://render.com) нажми **New → Web Service** и выбери репозиторий.
   Или выбери **New → Blueprint**, тогда настройки возьмутся из `render.yaml`.
3. Если настраиваешь вручную: Runtime `Node`, Build Command `npm install`, Start Command `npm start`.
4. Во вкладке **Environment** добавь переменные:
   - `STEAM_API_KEY` — ключ с https://steamcommunity.com/dev/apikey (в поле домена можно написать адрес своего сайта на Render).
   - `STEAM_ID` — необязательно. SteamID64, ссылка на профиль или имя из ссылки. Это же можно ввести прямо на сайте в «Настройки».
5. Нажми **Create Web Service**. Через пару минут сайт будет доступен по адресу вида `https://lifeline.onrender.com`.

Без `STEAM_API_KEY` сайт работает в демо-режиме: таймлайн и статистика доступны, пример данных загружается кнопкой.

### Чтобы Steam видел Blender

- В Steam Blender должен быть в библиотеке (он там есть как программа), и запускать его нужно через Steam.
- В профиле Steam → «Редактировать профиль» → «Приватность» открой **«Профиль»** и **«Игровую информацию»** для всех. Иначе API не покажет, что запущено.

## Как это работает и какие есть ограничения

- Задачи и записанные сессии хранятся в `localStorage` браузера. В «Настройках» их можно скачать и загрузить обратно.
- Steam API не отдаёт историю сессий, только то, что запущено прямо сейчас. Поэтому LifeLine спрашивает Steam раз в минуту и сам складывает ответы в сессии. **Пока вкладка закрыта, сессии не записываются.** Блок «Steam за 2 недели» в статистике показывает, сколько часов Steam насчитал, а сколько успел записать LifeLine.
- Бесплатный тариф Render усыпляет сервис через 15 минут без запросов, поэтому постоянный фоновый опрос на нём невозможен. Если нужна запись «в фоне», понадобится платный тариф и база данных для сессий.

## Локальный запуск

```bash
npm install
STEAM_API_KEY=твой_ключ npm start
# открой http://localhost:3000
```

## Структура

```
server.js          Express: статика и прокси к Steam Web API (ключ остаётся на сервере)
public/index.html  разметка
public/style.css   оформление
public/app.js      таймлайн, редактор, Steam-учёт, статистика
render.yaml        описание сервиса для Render
```
